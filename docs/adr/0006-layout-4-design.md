# The page is three tabs

ADR 0008 supersedes where the activity list sits, which columns a search result uses, and the serif title. The shared chart slot and the three regions below still stand.

The book, a listing, and a trade no longer stack on one long page. One chart slot changes with the tab, so the page stays short and a listing chart is the same width as the book chart.

Layouts 1–3 kept the equity chart, the trade form, the listing list, the listing detail, and the history in that order. The listing chart sat inside the detail and came out narrower than the book chart. The product spec also kept both charts on the page at once, so choosing a row would not replace the book chart. This replaces that. Choosing a listing changes the chart that is already there.

The tabs are one group, aligned left. They follow the Geist font switcher: a light track, and the selected tab as a dark filled pill. The labels are Totals, Tickers, and Buy/Sell. Tickers is only the label. The thing on that tab is a listing.

Totals shows the book's equity chart, with the book figures above it, and the listing list beneath the chart. It does not show the trade form, and it does not show a listing's own chart. History stays at the bottom.

Tickers keeps the chart in one place and puts the listing's own facts around it. The identity line from Layout 3's first detail frame — symbol, name, exchange, and trading currency — is the header above the chart. The listing chart fills the parent, the same width as the book chart on Totals. The figures from Layout 3's second detail frame sit beneath the chart: shares, average cost, mark, market value, weight, day gain, total gain, realized gain, day return, and total return. The listing list sits under those figures. Choosing a row replaces the header, the chart, and the figures. History stays at the bottom.

Buy/Sell shows the trade form. Cash stays at the top of the form, as on Layout 3. A search lists the listings it found in the listing list's table, not in a second table design. History is not on this tab.

The page title is "Paper Portfolio". It is small, bold, and serif, and it stays secondary to the book. The rest of the page stays in Geist. The ground stays Layout 3's gray, with a light paper grain so the gray is not a flat fill.

The long column was the other option. It kept every region in view, and it left the listing chart narrower than the book chart.
