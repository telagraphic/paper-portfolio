# A listing remembers its name

Layout 4 prints a name beside the symbol. The book identifies a listing by its symbol and exchange. Search returns the name for that request and then drops it. The name is remembered on the listing. It does not change cash, shares, fills, or gains.

A trade that starts from a search stores that hit's name for the listing. A later search trade for the same listing replaces it. A manual trade does not clear a name already stored. The page shows the symbol wherever the design shows a name and none is stored.

Storing the name on every trade, or printing the symbol in that slot, were the other options.
